# 免费自助外链筛选规则设计

## 目标

把 `screening-backlinks` 收紧为一套可重复测试的行动规则，回答一个具体问题：

> 这个网站是否值得用户现在亲自免费注册或提交，以获得可用于 SEO 的公开外链？

最终不使用 A/B/C/D/F 或任何综合评分。对用户的行动结论只有：

- `做`
- `不做`
- `信息不足，先不做`

`信息不足，先不做` 不是质量等级。它表示候选仍可保留，但当前证据不足，不能让用户先注册再碰运气。

## 范围

本规则只处理：

- 普通用户可自助注册后发布的免费外链；
- 普通用户可免费提交、等待平台审核的外链。

以下获取方式不进入当前执行清单：

- Editorial 引用；
- Outreach；
- PR、合作、联系站长；
- 自动聚合；
- 必须先具备 Podcast、企业资质、地区身份或其他用户当前不具备条件的机会。

这些机会可以留在候选库并记录获取方式，但当前行动结论为 `不做`。不能把它们描述成用户可以免费自助发布。

## 两个独立状态

为了避免误杀，系统必须分开记录：

1. **候选状态**：`保留` 或 `淘汰`；
2. **当前行动**：`做`、`不做` 或 `信息不足，先不做`。

找不到自助入口、获取方式未知或属于 Outreach，只能阻止当前行动；不能据此证明机会不存在。

只有直接证据证明网站死亡、恶意、纯链接农场、目标发布功能永久关闭或目标发布形式无法产生外链时，才淘汰候选或对应 placement。

## `做` 的必要条件

只有以下条件全部确认，当前行动才允许为 `做`：

1. 精确的 Submit、Add listing、Create profile、New post 或同等入口当前可访问；
2. 普通用户可以使用该入口，不需要联系站长、提交 PR、受邀或先建立长期社区声誉；
3. 免费档不要求付款、绑卡、购买积分、购买审核、强制 reciprocal link/badge 或升级套餐；
4. 免费档会生成公开、无需登录即可访问的稳定页面；
5. 免费档会在该公开页面展示可点击的目标网站链接；
6. 实际链接是直接指向目标站的外部 `<a href>`，不是纯文本或仅有平台内部跳转地址；
7. 同类型、同免费档的真实成品页证明链接为 Dofollow：`rel` 缺失、为空，或只包含 `external`、`noopener`、`noreferrer`；
8. 最终外链所在页没有 `noindex`：HTML `meta robots`、HTTP `X-Robots-Tag` 或等效平台规则均不得包含 `noindex`；
9. 页面返回正常内容，不是死亡页、停放页、恶意页或仅登录后可见；
10. 没有直接证据证明该 placement 属于无真实用户价值的垃圾链接农场。

任何必要条件未确认，都不能输出 `做`。

## `不做` 的确定条件

任一条件被直接证据确认，当前行动必须为 `不做`：

- 精确提交入口已经失效或目标发布功能已经关闭；
- 普通用户不能自助或免费审核提交，只能 Editorial、Outreach、PR、合作或联系站长；
- 免费只覆盖注册、建档或提交，Website 展示、公开页面或外链需要付费；
- 免费试用要求绑卡，或要求购买积分、审核、套餐、reciprocal link/badge；
- 免费成品页不展示 Website；
- Website 只是纯文本、不可点击或只形成平台内部跳转链接；
- 实际链接包含 `nofollow`、`ugc` 或 `sponsored`；
- 最终外链所在页包含 `noindex`；
- 页面仅登录后可见、没有稳定公开 URL，或会明确短期自动删除；
- 网站死亡、停放、恶意、钓鱼，或该 placement 被直接证据确认属于垃圾链接农场；
- 目标机会要求用户当前不具备的硬条件。

`不做` 只否定当前 placement 或当前获取方式。除非证据是域名级的死亡、恶意或停放，不得据此否定同一域名的其他 placement。

## `信息不足，先不做`

出现以下任一情况，必须输出 `信息不足，先不做`：

- 只知道竞品曾经有 backlink，但不知道获取路径；
- 首页写着 Free、Submit、Join Free 或 Add business，但没有证明免费档公开 Website；
- 价格、Website 权限或发布结果隐藏在登录后；
- 没有找到同类型、同免费档的真实成品页；
- 最终 `rel` 无法从原始 HTML 验证；
- 页面是否含 `noindex` 无法直接验证；
- 页面 canonical 指向其他 URL，且无法确认该 placement 的 SEO 行为；
- 当前工具遇到登录墙、CAPTCHA、403、地区限制或渲染限制；
- 官方说明和真实成品页互相冲突，尚未解决冲突。

该状态下：

- 不让用户注册或填写长表单；
- 保留候选和已有证据；
- 明确写出缺失的唯一关键事实和可行的替代验证方法；
- 不把缺失值写成 `0`、Nofollow、免费、不能发布或垃圾站。

## 强制验证顺序

1. 打开候选的精确 backlink 或来源页面，确认机会确实存在；
2. 判断获取方式：自助、免费审核、条件型、Editorial/Outreach、自动聚合、未知或不可复制；
3. 打开精确提交入口，不能只看首页宣传；
4. 检查 Pricing、FAQ、Guidelines、Terms、Free vs Paid、reciprocal 要求和隐藏收费；
5. 找到同类型、同免费档的真实公开成品页；
6. 检查 Website 是否显示、是否可点击、是否直接外链以及原始 `rel`；
7. 检查 HTTP 状态、公开可见性、`meta robots`、`X-Robots-Tag` 和 canonical；
8. 检查网站是否仍真实运营，排除死亡、恶意和有直接证据的垃圾 placement；
9. 最后输出行动结论、候选状态、理由、证据 URL、检查时间和仍未确认的事实。

不得为了节省研究步骤而让用户先注册再验证免费外链是否存在。

## 证据规则

- 历史竞品 backlink 只能证明“曾有链接”，不能证明当前普通用户可以复制；
- 免费注册、免费 profile、免费提交和免费 backlink 是四个不同事实；
- 官方 Pricing、FAQ、Terms 和提交表单用于证明政策与权限；
- 同类型、同免费档的真实成品页用于证明最终技术行为；
- 付费成品页不能证明免费档行为；
- 站长文章不能证明用户 Profile、Directory 或 Comment 行为；
- 平台主页可索引不能证明具体用户页面可索引；
- Google 当前没有搜索结果，不等于页面含 `noindex`；只有直接 `noindex` 证据才触发本规则的 `noindex` 硬拒绝；
- 官方说明与真实成品行为冲突时，保留冲突并输出 `信息不足，先不做`，直到查清同档位行为；
- 每个结论必须保留证据 URL 和检查时间，因为免费档和链接规则会变化。

## 指标使用

DR、流量和域龄不能代替最后一层验证，也不能单独决定 `做` 或 `不做`。

- 高 DR 不能挽救付费、Nofollow、`noindex` 或无公开链接；
- 低 DR、低流量、未知流量或年轻域名不能单独触发 `不做`；
- 缺失或查询失败不能写成 0；
- 指标只用于发现高 DR/低真实活动等矛盾，辅助检查垃圾风险。

垃圾 placement 必须有直接页面证据。相同模板、低流量或单一异常指标只能作为调查线索，不能单独淘汰。

## 固定输出格式

每个候选必须按以下顺序输出：

1. `当前行动`：做 / 不做 / 信息不足，先不做；
2. `候选状态`：保留 / 淘汰；
3. `获取方式`：自助 / 免费审核 / 条件型 / Editorial-Outreach / 自动聚合 / 未知 / 不可复制；
4. `核心原因`：一句话；
5. `免费 backlink`：已确认 / 未确认 / 否；
6. `公开外链`：已确认 / 未确认 / 否；
7. `Link rel`：Dofollow / Nofollow / 未确认，并记录原始 `rel`；
8. `Indexability`：无 noindex / noindex / 未确认；
9. `证据`：提交入口、政策页面、真实成品页；
10. `技术限制或下一步`：只写仍缺失的关键验证；
11. `检查时间`。

不得输出 A/B/C/D/F、综合分数、概率分或“大概率免费/大概率 Dofollow”。

## 行为回归场景

修改 Skill 前先用当前规则运行以下场景并记录失败；修改后对相同场景复测：

1. **免费注册但 Website 付费**：必须 `不做`，不能因为 Join Free 判 `做`；
2. **竞品有 Editorial 链接**：当前行动 `不做`，候选保留为 Editorial/Outreach，不能描述成自助发布；
3. **Dofollow + noindex**：必须 `不做`；
4. **Nofollow + indexable**：按当前目标必须 `不做`；
5. **首页有 Submit、精确入口死亡**：不能判 `做`；保留候选，除非证明发布功能永久关闭；
6. **没有同档位成品页、`rel` 未知**：必须 `信息不足，先不做`；
7. **免费、公开、直接 Dofollow、无 noindex**：必须 `做`；
8. **登录墙/CAPTCHA 阻断验证**：必须 `信息不足，先不做`，不能猜；
9. **竞品旧链接存在但当前获取路径未知**：必须保留候选，不能判当前可做；
10. **Google 暂未搜到页面，但无直接 noindex 证据**：不能仅据此判 `noindex` 或淘汰；
11. **同一域名 Profile 不合格、Editorial 仍存在**：只否定 Profile placement，不能域名级删除；
12. **高 DR、零流量但页面证据不足**：不能仅凭指标淘汰，必须继续检查真实页面。

## 非目标

本次不做：

- 自动提交外链；
- 绕过登录、CAPTCHA、电话、身份或地区限制；
- 保证平台审核通过；
- 保证未来 Google 收录；
- 实现新的 DR、流量、域龄或索引 API；
- 修改飞书字段、评级枚举或持久化代码；
- 为 Editorial/Outreach 设计执行流程。
