# Historical Implementation Records

Everything under `docs/superpowers/` is a point-in-time implementation plan or design specification.

These files are preserved because they document why earlier repository and runtime decisions were made. They are **not** the current BacklinkOS operating contract.

In particular, older plans may state that a capability was not yet implemented, require A/B/C/D/F ratings, or describe persistence/architecture gaps that have since changed.

For current behavior use, in order:

1. `../../.agents/skills/discovering-backlinks/SKILL.md`
2. `../../.agents/skills/screening-backlinks/SKILL.md`
3. `../REPOSITORY_ARCHITECTURE.md`
4. `../V4_PRODUCT_STRATEGY.md`

Do not update historical plans merely to make them match the present. Add or update current documentation instead.
