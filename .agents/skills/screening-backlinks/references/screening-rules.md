# 筛选规则

## 获取方式

只使用四种：

- **免费**：无需付款，也不强制给对方回链。可选的 Featured、加速审核、首页曝光等付费升级不改变“免费”。
- **免费换链**：无需付款，但必须给对方 reciprocal backlink。
- **付费**：想获得符合要求的 Follow 外链必须付款。免费层只有 Nofollow、付费层才 Follow，也归这里。
- **不确定**：当前无法确认是否存在合格的免费/换链路径。

## 最终链接

必须验证当前同一路径产生的公开结果页。

保留需要同时满足：

1. 页面公开可访问；
2. 页面允许被搜索引擎索引；
3. 有直接指向外部目标网站的 `<a href>`；
4. `rel` 不含 `nofollow`、`ugc`、`sponsored`。

以下直接回收：

- Nofollow、UGC、Sponsored；
- 只有站内跳转或跟踪包装链接，不能得到直接外链；
- 没有 Website URL；
- 只有付费才能得到合格 Follow 链接；
- 提交/发布入口已关闭；
- 最终页明确 `noindex`；
- 网站死亡或明显为垃圾/恶意站。

遇到 CAPTCHA、必须登录、人工审核、暂时无法生成样例等情况，不等于回收。只有关键结果无法确认时才放“待确认”。

## 限制条件

AI-only、SaaS-only、地区、公司资料、原创文章、GitHub 项目等只写入“条件/限制”。Screening 不替任何具体项目判断能否满足。
