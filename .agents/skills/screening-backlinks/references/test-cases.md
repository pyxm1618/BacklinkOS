# 回归测试

以下行为必须成立：

1. `discovering-backlinks` 传来的 source project、Organic Traffic、AS、backlinks_num、first_seen、last_seen、Semrush historical Follow 等事实直接使用，不重新查询。
2. 不出现“Quick I Ching 是否有资格”“当前项目是否适合”等判断。
3. 免费且当前可获得、最终为 Follow、页面可索引 → `获取方式=免费`、`处理结果=正式机会`，进入外链总表。
4. 必须 reciprocal backlink，但不收费，且最终为 Follow、页面可索引 → `获取方式=免费换链`、`处理结果=正式机会`，进入外链总表。
5. 必须付款才能得到合格 Follow 链接 → `获取方式=付费`、`处理结果=付费排除`，不是回收。
6. 免费层 Nofollow / UGC / Sponsored，付费层才 Follow → 合格 Follow 的获取方式为 `付费`，`处理结果=付费排除`；不得进入正式总表。
7. 只有免费路径且最终 Nofollow / UGC / Sponsored → 保留实际获取方式，`处理结果=回收`。
8. 免费提交按钮存在，但无法确认最终公开页是否有合格 Follow 外链 → `处理结果=待确认`；获取方式若已确认免费则保留 `免费`，否则为 `不确定`。
9. 最终页明确 noindex → `处理结果=回收`。
10. DR 很低、AS=0 或流量很低，但满足免费 + Follow + 当前可获得 + 可索引 → 仍可进入总表；这些指标只影响排序。
11. 同一域名的 Profile 和 Directory 有不同操作入口时，可保存为两个机会。
12. 已在总表中的同一机会再次被发现 → 更新证据/最近验证，不追加到“新增记录”。
13. AI-only、SaaS-only、地域等只记录为条件，不根据任何具体推广项目淘汰。
14. 用户说“继续/全部执行/筛完/做完”时，只处理一个样本批次后停止属于失败；必须持续处理直到 `待筛选=0`，除非遇到明确外部阻塞。
15. `待筛选>0` 时不得回复“全部完成”。若被阻塞，必须同时报告剩余待筛选数量和阻塞点。
16. 允许网络级批量回收，但必须有共同运营方/品牌/模板/机制、明确卖链行为或公开调查证据；只凭域名命名相似不得批量淘汰。
17. 网络级批量规则必须保存匹配规则、处理状态、原因、证据 URL、核验日期和适用范围，并让后续同规则候选自动继承状态。
18. 已验证批量案例：`seo-anomaly-*` 可依据公开网络调查及运营方自身 PBN/backlink 服务说明批量回收；`bhs-links-*` 可依据公开页面标题/描述中的 Hardcore Black Hat SEO / @bhs_links 网络说明批量回收。
19. 每轮写入后必须重新统计 `待筛选`；只要仍大于 0，全量模式继续下一批。
20. 当前 listing DOM 明确 `rel=nofollow`，即使 Semrush 历史 10/10 Follow，也必须采用当前 DOM，处理结果为回收。
21. 当前官方 Submit/Pricing 与历史 Semrush 冲突时，当前官方机制事实优先；但最终 link rel 仍优先由当前结果页 HTML/DOM 决定。
22. 历史 0 Follow 不等于回收；如果当前免费路径的最终 HTML 为普通 Follow 且可索引，应进入正式机会。
23. 搜索暂时没找到提交入口、样例页或价格规则，不得仅凭“没找到”进入回收；应记录缺失事实并进入待确认。
24. CAPTCHA、登录、邮箱验证、人工审核等阻塞不等于回收。
25. domain-level evidence 无法识别机制、而 exact historical source page 可能有帮助时，必须返回 `source_url_enrichment_required` 给 Discovery，而不是猜 source URL 或直接回收。
26. 收到 `source_url_enrichment_required` 的补证后，历史 `source_rel_observation` 仍只是发现事实，不能覆盖当前结果页的更高优先级证据。
27. 运行表状态迁移必须按“目标写入 → 回读确认 → 源清理”；如果目标回读失败，不得清源。
28. 包含 ARRAYFORMULA / 公式列 / 路由计算列的表不得整行清理，只清当前流程拥有的数据单元格。
29. 迁移后必须重新核对总量、空状态和各处理结果集合；不能依赖公式优先级掩盖重复状态。
30. A/B/C/D 可以作为内部解决路线帮助排序，但不能作为业务评级、正式机会准入或淘汰依据。
